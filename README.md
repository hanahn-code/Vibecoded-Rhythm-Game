# Pulsegrid

A browser-based five-lane rhythm game that analyzes local audio, estimates BPM, and generates difficulty-scaled note charts. Audio never leaves the browser.

## Run locally

Serve the folder with any static web server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

Controls: **D F J K L** or tap/click the lanes.
